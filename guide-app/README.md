# TV Guide - Standalone Service (Android Compatible)

This is the standalone TV Guide application that can be wrapped for Android devices.

## Structure
- Separated from admin dashboard
- Can be deployed independently
- Android WebView compatible
- Public-facing guide interface

## Features
- Channel browsing
- EPG guide viewing
- Featured channel display
- Clean UI optimized for TV boxes and mobile

## URLs
- Development: http://localhost:3001
- Production: https://guide.yourdomain.com

## Android Integration
See `/app/android/README.md` for wrapping instructions.
