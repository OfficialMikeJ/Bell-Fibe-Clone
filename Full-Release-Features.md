# StreamVault — Full Release Features

These features are planned for the full public release of StreamVault. They are **not** part of the current alpha/beta build. This file will be updated when the service is ready for full release.

---

## P1 — TV Tuner Integration
- Interface backend with a hardware TV tuner for streaming Free-to-Air live channels
- Connect actual HLS/RTSP stream URLs to channels
- Live TV channels with real broadcast feeds

## P2 — CVR Automated Recording
- Background job for Cloud Video Recording
- Scheduled recording triggers based on EPG program times
- Storage management and retention policies

## P3 — Push Notifications & Watch History
- Push notifications to connected devices
- User watch history tracking and "Continue Watching" feature
- Admin push notification management for tickets

## P4 — Admin App Enhancements
- Push notifications for support tickets
- QR code scanner for device details
- On-device diagnostics tooling

## Backlog
- VOD Content Ingestion system (bulk upload for movies/shows)
- Credential rotation option (admin-triggered)
- Advanced analytics and reporting
